# 설계 결정 기록

## 상태 정의

- `확정`: 현재 구현 기준으로 사용한다.
- `베타`: 배포됐지만 운영 검증과 고도화가 남았다.
- `보류`: 현재 범위에서는 구현하지 않는다.
- `폐기`: 더 이상 사용하지 않는다.

## 남은 결정

### 앱스토어 계정 연결

Apple·Google·이메일 중 지원할 공급자, 기존 앱인토스 계정과의 연결 증명, 계정 병합·분리 정책을 결정해야 한다. Todo 도메인은 공급자에 의존하지 않고 `account_identities` adapter만 확장한다.

### 증분 동기화와 충돌

전체 스냅샷의 사용량·실패율을 측정한 뒤 outbox와 멱등 operation을 추가한다. 권장 방향은 version 충돌 감지, 삭제 우선, 자동 병합할 수 없는 제목·메모의 로컬 충돌 보관이다.

### 삭제·보존

계정 삭제 요청, 모든 세션 폐기, 서버 tombstone 보존 기간과 하드 삭제 시점을 개인정보처리방침과 함께 확정해야 한다. 일반 소프트 삭제는 30일을 초기 검토안으로 둔다.
